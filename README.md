# Overview

This app is continuing to work on a full stack site that I am creating for my comic "Wildly Imaginative". This site has a MySQL database, a C# API and a TypeScript front end that runs with React.
I have created four pages: a landing or home page that will display a comic, a page that lists the characters with hyperlinks to their own details pages, a details page that shows information about the characters, and an about page with general information about the comic.

## How to Run

1. Set up and start the [Comic API](https://github.com/JLKohl/ComicApi). Follow its **Getting Started** steps.
2. `npm install`
3. `npm start`, then open localhost:5173
4. `npm run check` to test the API from the terminal


# Web Pages

A nav bar at the top links the Home, Characters, and About Comic pages. Clicking a character's name opens its details page, and a back link will take you back to the characters page. 

- **Home Page** `/`: This is the home page that displays the comics. It includes a dropdown where you can select the comic you would like to read (currently has filler content). The dropdown options and the comic details come from the comic API that was created previously.
- **Characters** `/characters`: This page shows a list of characters that can be searched for individually in the search bar. The list is built from the API with `map()` and the search filters live as you type. When you click on a character, it will take you to the details page for that character.
- **Character Details** `/characters/:id`: This page will display a picture (coming soon) and the details of each character. This page reads the id from the URL and gets the character's information from the API. Currently it has filler information.
- **About Comic** `/about-comic`: This will contain information about the comic. Currently holds filler information generated by ChatGPT. This page is static.
